Integrated compiler and runtime

VIB — Vayu Integration Backend

VIB is the integrated compiler/runtime system inside the Vayu repository. It implements the Integrator architecture and uses the existing Vayu frontend. It is not a separate language or a required standalone executable.

Current implementation

VIR execution is implemented for a growing subset

The active VIB path lowers supported Vayu constructs to VIR, verifies the representation, and executes it with the VIR interpreter. The supported scope includes arithmetic, strings and methods, functions and recursion, control flow, collections, module imports, and selected built-ins. Native machine-code generation is still planned, so VIB must not be described as a finished native compiler.

Implemented VIR subset

Arithmetic and comparisons, string constants/operations/methods, locals, functions, calls, recursion, return plumbing, control flow, collections and module imports have completed roadmap milestones. Exact support remains feature-gated.

Verifier and diagnostics

The verifier checks VIR structure, opcode operands, function/call constraints, empty modules and branch targets. Unsupported constructs must produce explicit diagnostics rather than false success.

VYE packages and cache

The opt-in --emit-vye writer, --run-vye reader/execution path, --dispatch=integrator, and --enable-cache/--cache-dir infrastructure are implemented. A .vye package requires a compatible Vayu runtime and is not a native OS executable.

Current work: Phase 10

Built-ins such as input and read_int and additional language coverage are in progress. Classes, exceptions, generators and closures should only be advertised as VIB-supported after their individual implementation and tests pass.

Capability and command reference

Capability status

--vib-status reports the Integrator's feature/capability information. Use the reported support level rather than assuming interpreter support transfers to VIB.

IR inspection

--dump-ir exposes VIR output for supported programs and helps diagnose lowering or verification issues.

Package output

--emit-vye <path> writes a package, while --run-vye <path> loads and executes a validated package.

Opt-in dispatch and cache

--dispatch=integrator selects Integrator routing. --enable-cache and --cache-dir enable artifact caching where supported.
