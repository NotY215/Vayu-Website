Integrated compiler architecture

VIB — Vayu Integration Backend

VIB is the integrated compiler/runtime system inside the Vayu repository. It implements the Integrator architecture; it is not a separate language, required standalone product or required executable.

Implementation status

Architecture scaffold, not a finished native compiler

The current VIB directory contains the Integrator API scaffold and documentation. The implementation explicitly reports that native code generation is not implemented yet. Use --run or --vm for execution on the current transition branch.

Vayu owns

Language semantics, VIR, verification, lowering decisions, native code generation, runtime contracts, artifact identity, cache validity, incremental invalidation and dispatch policy.

Platform tools may provide

Final linking, operating-system interfaces, system libraries, SDK files and debugging tools behind narrow, documented interfaces.

Next engineering gates

Establish baseline and conformance evidence, define shared semantics, implement deterministic VIR, verify invalid input, then build a minimal native target with tests.

Performance policy

Caching, incremental builds, adaptive dispatch and native speed improvements are hypotheses until implemented and measured with reproducible workloads.
