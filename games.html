Build your own OG games in Vayu.

When the compiler is complete, you’ll write games like these in a few lines of Vayu. canvas, draw_rect, on_tick, on_touch will be part of the standard library. Native output, tiny binaries, cross-platform. 

import nova.game as g

w = g.window(800, 500, "Pong")
ball = g.circle(x=400, y=250, r=8)
paddle = g.rect(x=20, y=200, w=12, h=90)

g.on_touch(dy -> paddle.y = clamp(dy, 0, w.h - paddle.h))
g.on_tick(dt ->
    ball.move(dt)
    if ball.hits(paddle): ball.bounce()
)
w.run()
