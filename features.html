Capabilities

One language. Many directions.

The current language already covers a substantial core, while later phases expand Vayu into a complete development ecosystem.

PHASE 27 · ACTIVE
λ

Functions & lambdas

Functions, recursion, lambdas, closures, generators, type parameters and higher-order values.

◇

Collections

Lists, maps, tuples and sets with slicing, iteration, sorting and collection helpers.

◎

Types & ownership

Inference, annotations, generics, constraints, unique/shared/weak references, raw pointers and references.

▣

OOP

Structs, classes, constructors, methods, inheritance, overriding, static members and visibility.

!

Runtime & standard library

Exceptions, modules, filesystem, time, JSON, regex, threading, networking, crypto, random, OS and math.

↗

Native interoperability

C FFI, function pointers, external libraries, malloc/free and supported struct-by-value FFI.

⌘

Python bridge

Native CPython loading with import, attribute, call, eval, exec, list, dict and reference-management APIs.

⚙

VCB native path

Vayu lowers supported native programs to VCBIR, then VCB generates x86-64 PE or ELF output and emits only reachable runtime helpers.
