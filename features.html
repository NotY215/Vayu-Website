Capabilities

One language. Many directions.

The current language already covers a substantial core, while later phases expand Vayu into a complete development ecosystem.

PHASE 00 · ACTIVE
λ

Functions & lambdas

Functions, direct calls, parameters, recursion, return values and conversions are supported in VIB; lambdas, closures and generators remain pending there.

◇

Collections

VIB supports list, map, tuple and set literals, indexing and len() in its documented subset; advanced collection behavior varies by execution route.

◎

Types & ownership

Static analysis and type checks are part of the frontend. Advanced ownership, pointer and generic constructs should be checked against the selected execution route.

▣

OOP

Structs, classes, constructors, methods, inheritance, overriding, static members and visibility.

!

Runtime & standard library

Exceptions, modules, filesystem, time, JSON, regex, threading, networking, crypto, random, OS and math.

↗

Native interoperability

C FFI, function pointers, external libraries, malloc/free and supported struct-by-value FFI.

⌘

Python bridge

Native CPython loading with import, attribute, call, eval, exec, list, dict and reference-management APIs.

⚙

VIB compiler architecture

VIB is the in-repository Integrator system. VIR lowering, verification and execution, .vye packaging, opt-in dispatch and artifact caching are implemented for a growing subset. Native machine-code generation remains planned.
