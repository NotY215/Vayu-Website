Language

Custom Vayu syntax. Not pseudocode.

Vayu source files use .vyu. The syntax is indentation-based and custom to the language: Python-style blocks, static typing, generics, ownership, C FFI, a CPython bridge, and a full standard library. Everything below is taken from the live compiler.

What the lexer sees

Blocks are driven by INDENT / DEDENT tokens. Comments are # only. Single-quoted single characters become char literals, everything else becomes a string.

# line comments indent / dedent 0b / 0o / 0x 1.25e3 true / false / none True / False / None "strings" 'strings' 'c' char
Types

Static typing with inference.

Vayu runs a type checker over explicit annotations, and infers types for locals that don't declare one.

types.vyuprimitives · generics · ownership
# Inferred
x    = 5
y    = 3.14
name = "Vayu"
flag = true

# Explicit
a: int   = 10
b: float = 2.5
c: str   = "Vayu"
d: bool  = true

# Collections
nums:  list<int>      = [1, 2, 3]
ages:  map<str,int>   = {"alice": 30}
point: tuple<int,int> = (3, 4)
tags:  set<str>       = set(["a", "b"])

# Pointers and ownership
raw: ptr<int>       = malloc(sizeof(int))
u:   unique<Node>    = Node(1)
sh:  shared<Node>    = u
wk:  weak<Node>      = sh.weak()

The type system knows

intfloatbool strcharbytes Noneany list<T> map<K,V> tuple<T…> set<T> ptr<T> ref<T> unique<T> shared<T> weak<T> struct class enum function

int promotes to float. Generic unification and type-parameter substitution are handled by the checker. Assigning "hello" to an int is a compile-time error.

control.vyuconditionals · loops

    print("negative")

    print("zero")

    print(i)
    i = i - 1

    print(color)

    if n == 5: continue

match.vyumatch / case · binders · guards · tuples
match n:
    case 0:        return "zero"
    case 1:        return "one"
    case x if x < 0: return "negative"
    case _:        return "many"

match (10, 20):
    case (x, y):
        print(x + y)

Loop control: break, continue and pass are hard keywords. range() accepts 1, 2 or 3 arguments: range(5), range(2, 8), range(0, 10, 2).

functions.vyutyped def · recursion · closures
def add(a: int, b: int) -> int:
    return a + b

def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

Scope helpers

with · defer · yield

scope.vyuwith · defer · yield
# with — auto cleanup via __enter__ / __exit__
with Resource("first") as v:
    print("inside, v = " + str(v))

# defer — LIFO execution at scope exit
def process(a: int, b: int) -> None:
    defer print("defer-second")
    defer print("defer-first")
    print("processing " + str(a + b))

# generators
def countdown(n: int):
    while n > 0:
        yield n
        n = n - 1

g = countdown(3)
print(next(g))
for x in countdown(5):
    print(x)

How they behave

with relies on the type having __enter__ and __exit__. The parser handles both with resource: and with resource as name:.

defer is a soft keyword. Deferred expressions are desugared into nested try/finally blocks so they run in LIFO order. Must appear at the top of a block.

yield turns a def into a generator. The VM maintains generator state across calls. Cleanup in finally runs when the generator is torn down.

Memory

Ownership, pointers, unsafe.

memory.vyuownership · pointers · malloc
# Address-of and dereference
x = 42
p = &x
print(*p)          # 42
*p = 7             # write through pointer

# Typed pointer
def double_ptr(p: ptr<int>) -> int:
    return *p * 2

# Ownership — unique is move-only
a: unique<Resource> = Resource("first")
b: unique<Resource> = a          # moves a into b

# shared / weak
sh: shared<Node> = make_node()
wk: weak<Node>   = sh.weak()
got: shared<Node> = wk.upgrade()

# Raw allocation
raw: ptr<int> = malloc(sizeof(int))
free(raw)

# unsafe block for low-level ops
unsafe:
    raw = malloc(8)
    *raw = 99
    free(raw)

Ownership types

unique<T> shared<T> weak<T> ptr<T> ref<T>

unique<T> is move-only — the type checker tracks moved_ scope and refuses use-after-move. weak<T> is non-owning; .upgrade() desugars to a shared reference. ref<T> resolves to the underlying T at type-check time.

Pointer arithmetic, indexing through pointers (p[i]), assignment (p[i] = v), and &arr[i] / &obj.field / &m[k] for live lvalue references are supported across the tree-walker, VM and native backends.

C FFI and the CPython bridge.

ffi.vyuextern "C"
extern "C":
    def strlen(s: str) -> int

py.vyuCPython bridge
import py

py.init()
print(py.version())

m = py.import("math")
print(py.getattr(m, "pi"))
print(py.call(py.getattr(m, "sqrt"), [16]))

py.setattr(obj, "name", py.str("Alice"))
py.decref(m)

FFI is native-backend only. extern "C" blocks parse and type-check on all backends, but calling an external function from the tree-walker or VM raises "extern C functions can only be called from the native backend". Native supports str ↔ char* bridging, function pointers, C callbacks, and struct-by-value (small single-field).

py module is native-backend only. py.init() on the tree-walker/VM raises "py.init() requires the native backend".

Grammar

The shape of a Vayu program.

grammar.ebnfinformal · from parser
program   ::= { statement } EOF

statement ::= def | struct | class | if | while | for
            | return | try | raise | import | from_import
            | const | enum | with | extern | unsafe
            | yield | match | pass | break | continue
            | annotated_assign | unpack_assign | expr_or_assign

block     ::= ":" NEWLINE INDENT { statement } DEDENT

def       ::= "def" IDENT [ "<" type_params ">" ] "(" [ params ] ")"
              [ "->" type ] block

class     ::= "class" IDENT [ "(" IDENT ")" ] ":" NEWLINE INDENT
              { visibility? ( field | "static"? def ) } DEDENT

match     ::= "match" expression ":" NEWLINE INDENT { case } DEDENT
case      ::= "case" pattern [ "if" expression ] ":" block

try       ::= "try" block { "except" [ type [ "as" IDENT ] ] ":" block }
              [ "finally" block ]

with      ::= "with" expression [ "as" IDENT ] block
extern    ::= "extern" STRING ":" NEWLINE INDENT { fn_decl } DEDENT
unsafe    ::= "unsafe" block
Backends

Three execution paths. One source.

🖥️

Tree-walking interpreter

Fastest to start, slowest to run. Used for scripting and testing the compiler front-end.

vayuc --run file.vyu

📦

Bytecode VM

Compiles to bytecode, runs on a stack VM with a peephole optimizer. Balanced speed.

vayuc --vm file.vyu

⚡

Native compiler

Emits native code through QBE + GCC. Required for C FFI and the CPython bridge.

vayuc --native file.vyu

Soft keywords

These words are not reserved by the lexer — they remain identifiers and are reinterpreted contextually by the parser. That means you can still use them as variable names.

match case defer namespace static public private protected

self is likewise not a keyword — it's a naming convention enforced by the class parser.
