Vayu language

Static typing and inference, functions, closures, generators, collections, OOP, exceptions, modules, ownership, pointers, C FFI and the CPython bridge.

Syntax reference

Compiler and tooling

The repository contains the C++ bootstrap/reference compiler plus vls, vfmt, vlint, native execution paths and editor integrations.

Developer tooling

Package ecosystem

nva supports project setup, local and remote registry workflows, install/update, Git dependencies, dependency trees and publishing workflows.

AI and Python

Vayu includes native CPython loading and Python value/call interoperability. Broader NumPy, PyTorch, TensorFlow, ONNX and GPU work remains an ecosystem direction.

VCB backend reference

VCBIR

Typed SSA-style values, basic blocks, phi nodes, branches, jumps, calls, returns, memory operations, arithmetic, comparisons, conversions and string constants.

Code generation

The x86-64 backend handles integer and floating-point operations, control flow, stack slots, calls, phi lowering and runtime symbol references.

Windows PE

VCB writes PE images itself, builds imports, emits .text/.rdata/.idata sections, calculates checksums, pads small images and exposes header diagnostics.

Linux ELF

VCB writes ELF64 images, provides a syscall-based runtime subset, a brk-based bump allocator, list/map paths and Linux collection printing.

Runtime emission is demand-driven. Helpers are emitted when the module references them, with dependency closure used for transitive runtime requirements.

Current VCB runtime coverage

  • Process exit and character, line, space, bool, integer and float printing.
  • Windows runtime imports and native helpers.
  • Linux syscall output and brk-based bump allocation.
  • Lists: creation, push, get, set, length and printing.
  • Maps: creation, put, get, has, length and printing.
  • Strings: length, equality, prefix/suffix checks, contains, find, upper and lower.
  • Atomic PE and ELF writes plus structural header inspection.
