Vayu is an independent programming language and compiler project developed by NotY215, alongside compiler tooling and game-development projects.

About the developer

NotY215 is the project identity used across the developer's open-source work. Vayu focuses on a Python-like programming language with a native compiler backend. VCB is Vayu’s backend and intermediate representation toolchain, with ongoing work to expand language coverage, object emission, linking and runtime support.

Project work

Vayu and VCB are part of a wider collection of software projects. The development approach emphasizes readable source, documented architecture, practical tooling and clear roadmap boundaries.
