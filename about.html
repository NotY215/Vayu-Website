The idea

A language built to stay simple as it gets powerful.

Vayu combines approachable syntax with native compilation, static typing, object-oriented features, compiler optimization and a long-term ecosystem for software, games, systems and AI.

PHASE 00 · ACTIVE
◈

Language frontend

Vayu provides the .vyu language, lexer, parser, semantic analysis, tree-walking interpreter, bytecode compiler and VM. The integrated VIB path now lowers a supported subset into Vayu Intermediate Representation (VIR), verifies it, and executes it through the VIR interpreter.

⚡

VIB Integrator architecture

VIB is the integrated compiler/runtime system inside Vayu. VIR lowering, verification, interpretation, control flow, collections, module imports, `.vye` packaging and opt-in artifact caching are implemented for the supported subset. Native machine-code generation remains planned and is not yet available.

⌁

Developer tooling

Vayu includes the interpreter, bytecode VM, VIB/VIR execution route, `.vye` package commands, `--vib-status` capability reporting, and Vayu-IDE with IntelliSense and editor conveniences.
