FAQ

Questions about Vayu?

A quick reference for the language, compiler, current development status, native backend, tooling and roadmap.

PHASE 24 · IN DEVELOPMENT
What is Vayu?
Vayu is a Python-inspired programming language focused on readable syntax, static typing and native compilation. Its long-term scope includes software, games, systems and AI/ML workloads.
Is Vayu a Python implementation?
No. Vayu uses Python-like ideas and familiar syntax, but it is its own language with its own compiler, type system, runtime and .vyu source format.
What file extension does Vayu use?
Vayu source files use .vyu.
Is Vayu ready for production?
Vayu is still in active development. The current roadmap is at Phase 24, Native floats, so the toolchain and language are not yet presented as a finished production release.
What is Phase 24?
Phase 24 adds native floating-point support. It covers the float type and ABI, arithmetic and comparisons, native math functions and float collections, followed by migration of tensors away from Q16.16.
Why are floats being added before benchmarks?
The benchmark suite needs programs that resemble real workloads. Building benchmarks around integer-only arithmetic would distort comparisons with languages and workloads that naturally use floating-point computation.
How does Vayu compile native code today?
The current native path uses Vayu's compiler pipeline and QBE, with the generated native code linked through the existing toolchain. Phase 27 plans to replace that path with VCB.
What is VCB?
VCB, the Vayu Compiler Backend, is planned as a separate sister project. It will progressively move from object-file emission to direct code generation, linking/runtime integration, additional object formats and ARM64.
Will Vayu have a package manager?
Yes. Package-management work is already represented in the completed roadmap, including the nva tooling and registry-related functionality.
Does Vayu support AI and tensors?
Yes, the project already contains tensor, autodiff, neural-network and ONNX examples. Phase 24 is specifically planned to move tensor internals toward native floating-point representation.
Where can I see the complete roadmap?
Visit the Roadmap page for the full phase and subphase breakdown, including the planned benchmark and VCB work.
Where can I view the source code?
The main Vayu source repository is available on GitHub.
Can I contribute or report a problem?
Yes. Use the Vayu GitHub repository for source, issues and project discussions. For behavior or community concerns, follow the project's reporting guidelines.
