Vayu is an independent programming language and compiler project developed by NotY215, alongside compiler tooling and game-development projects.

About the developer

NotY215 is the project identity used across the developer's open-source work. Vayu focuses on a Python-inspired language with an interpreter, bytecode VM and an integrated VIB/VIR execution path. The supported VIR subset, verifier, .vye packaging, opt-in dispatch and artifact caching are implemented; native machine-code generation remains future work.

Project work

Vayu is part of a wider collection of software projects; VIB is the integrated compiler architecture inside the Vayu repository. The development approach emphasizes readable source, documented architecture, practical tooling and clear roadmap boundaries.
