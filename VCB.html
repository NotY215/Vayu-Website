Vayu Compiler Backend

VCB turns VCBIR into native executables.

VCB is a standalone C++20 backend for Vayu. Vayu owns .vyu source and frontend analysis. VCB consumes .vcbir and emits x86-64 native images.

Current backend

VCBIR parsing and printing, typed SSA-style IR, x86-64 code generation, runtime emission and direct PE/ELF writing.

⚡

Runtime

Demand-driven helpers, Windows imports, Linux syscalls, brk-based allocation, list/map support and string/collection printing.

⌘

Inspection

Use vcb dump for IR inspection, vcb headers for PE validation and vcb elfheaders for ELF structure inspection.
