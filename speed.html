Measurement rules

  • Use the same hardware and operating-system configuration for all languages in a comparison set.
  • Record Vayu and VCB revisions, target, optimization settings and runtime configuration.
  • Separate cold-start and warmed-up measurements where a runtime or JIT makes that distinction meaningful.
  • Run multiple iterations and report a representative statistic rather than a single lucky run.
  • Publish raw results with the harness so the displayed summary can be reproduced.
  • Do not publish projected numbers as if they were measured results.
